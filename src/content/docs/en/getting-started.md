PicFerry is an unofficial cloud-gallery download app: connect an account, browse photos and videos, and save media to a desktop folder or a mobile system photo library.

## What you can do today

- Add and connect **iCloud, Xiaomi, vivo, and OPPO** accounts. The add-account list also offers REDMI, POCO, iQOO, OnePlus, and realme; they use the Xiaomi, vivo, or OPPO cloud service. Adding HUAWEI and HONOR accounts is not available yet.
- Browse media, preview images, and download files. The default **copy** mode keeps cloud originals.
- Use **move** (download and delete cloud originals) where supported. Migration and explicit deletion from the gallery are separate actions; read [Security](/en/security/) before using them.
- Choose Chinese or English, system/light/dark themes, gallery density, and download settings. Default concurrency is **4**.

The [Status page](/en/status/) is the reference for authentication methods, platform capabilities, and operation limits. An implemented capability does not imply a downloadable installer; see [Download](/en/download/) for availability.

## Get started

1. Read [Security](/en/security/) for authentication, local storage, and cloud-deletion boundaries.
2. Open [Download](/en/download/) and choose the official package for your device. Current packages cover Linux x64, Windows x64, and Android. macOS, iOS, and HarmonyOS currently ship through app stores or other independent channels. You do not need source access to download official packages. Developers who already have source access can also follow [Build from source](/en/install/).
3. Follow the [GUI guide](/en/guides/gui/) to add an account, then use the authentication steps for [iCloud](/en/guides/icloud/), [Xiaomi](/en/guides/xiaomi/), [vivo](/en/guides/vivo/), or [OPPO](/en/guides/oppo/).
4. Copy a few photos and videos first. Verify their location and readability before starting a batch task.

There is no automatic sync or scheduling, and restarting a task is not resumable downloading. Selecting an album in the gallery does not scope batch downloads, and saving does not recreate cloud album structures. See [Status](/en/status/) for details.
