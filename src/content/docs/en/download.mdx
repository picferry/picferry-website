## Official packages

The list below shows the current official installers. After a new version is published, refresh this page. Download links appear only for packages that are confirmed available.

## Platforms and architectures

Official packages currently cover **Linux x64 (tar.gz), Windows x64 (zip), and Android universal APK**. Use the live list above for available versions, filenames, sizes, and SHA256 values.

- **x64**: Intel / AMD 64-bit processors.
- **universal APK**: contains multiple Android ABIs; it does not guarantee compatibility with every device or OS version.
- Desktop ARM64, macOS, iOS, and OHOS currently ship through app stores or other independent channels. Web is a UI preview only. See [Status](/en/status/) for capabilities.

After downloading, you can check SHA256 with `sha256sum <filename>` on Linux or `Get-FileHash <filename> -Algorithm SHA256` in Windows PowerShell. Both download links should deliver the same file. A hash confirms completeness; it does not replace source verification. This site currently recommends no unverified store listings.

## What to do next

- **App users**: read the [Overview](/en/getting-started/) and [GUI guide](/en/guides/gui/). If the list is empty, refresh later. For network or verification problems, try again or open the release notes.
- **Developers who already have source access**: follow [Build from source](/en/install/) to arrange sibling source directories and platform toolchains. Source access is required only for building from source, not for downloading official packages.

Read [Security](/en/security/) before connecting a real account.
