## Current availability

**As of 2026-10-24, this site provides no verified public installer links. No public release was found in the website repository's Releases, and GUI/Core could not be accessed publicly.**

This conclusion covers the public endpoints checked, not the existence of packages everywhere. See [Status](/en/status/) for the verification scope and API results. The [website repository's Releases](https://github.com/picferry/picferry-website/releases) is a public page you can inspect, not a verified installer link or a commitment to a future distribution channel.

This site currently has no verified store installation entry to recommend. It does not list unverified package filenames, CPU architectures, release dates, or download buttons that automatically become available. A native project and a publicly downloadable package are different things.

## What to do next

- **App users**: read the [Overview](/en/getting-started/) and [GUI guide](/en/guides/gui/) to understand the workflow. Assess installers using verified provenance, version, and integrity information rather than filenames or mirror descriptions alone.
- **Developers who already have source access**: follow [Build from source](/en/install/) to arrange sibling GUI/Core directories and platform toolchains. The public website repository is not a substitute for app source code.
- **Check your device**: consult the [platform matrix](/en/status/#platforms-and-save-destinations). Windows/Linux have native projects; Android/iOS/OHOS implement system-library saving. macOS currently lacks a native project, and Web is only a UI preview. None of these statements promises an installer.

Read [Security](/en/security/) before connecting a real account.
