**Adding HUAWEI accounts is not currently enabled.** Use the providers that the app actually offers.

## Current usage

- For new accounts, follow the [GUI guide](/en/guides/gui/). This page does not provide a workaround for the disabled account-creation entry.
- If you already have a configured HUAWEI account, use the connection and copy actions available in the current interface. Cloud deletion and batch moves are not enabled.
- Image previews, inline video, automatic sync, scheduling, and resumable downloading are not available in the app for this provider.

## Credentials and downloads

Keep cookies, sessions, and account identifiers in trusted storage. Sign in again when authentication expires. See [Download](/en/download/) for installers.
