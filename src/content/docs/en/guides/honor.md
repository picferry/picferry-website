**Adding HONOR accounts is not currently enabled.** Use the providers that the app actually offers.

## Current usage path

- For new accounts, follow the [GUI guide](/en/guides/gui/).
- Existing configured HONOR accounts can use the connection and copy actions available in the interface. Cloud deletion and batch moves are not enabled.
- Media previews, automatic sync, scheduling, and resumable downloading are not available in the app for this provider.

## Credentials and downloads

Keep Cookie files, saved sessions, account identifiers, and signed media URLs private. Share only sanitized information when reporting problems. Sign in again when authentication expires. See [Download](/en/download/) for installers.
