## 平台与架构

当前官方安装包面向 **Linux x64（tar.gz）、Windows x64（zip）、Android universal APK**。实际可用版本、文件名、大小和 SHA256 以上方列表为准。

- **x64**：Intel / AMD 64 位处理器。
- **universal APK**：包含多种 Android ABI；具体兼容性以设备和系统版本为准。
- 桌面 ARM64、macOS、iOS、HarmonyOS 当前通过应用市场或其他独立渠道发布；Web 仅供界面预览。完整能力见 [状态页](/status/)。

下载后可核对 SHA256：Linux 运行 `sha256sum <文件名>`，Windows PowerShell 运行 `Get-FileHash <文件名> -Algorithm SHA256`。两个下载入口应得到相同文件。哈希用于确认文件完整，来源以本页官方下载入口为准。商店入口以已核实的发布渠道为准。
