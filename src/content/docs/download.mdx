## 平台与架构

当前官方安装包面向 **Linux x64（tar.gz）、Windows x64（zip）、Android universal APK**。实际可用版本、文件名、大小和 SHA256 以上方列表为准。

- **x64**：Intel / AMD 64 位处理器。
- **universal APK**：包含多种 Android ABI，不表示适用于所有系统版本或设备。
- 桌面 ARM64、macOS、iOS、OHOS 当前通过应用市场或其他独立渠道发布；Web 仅供界面预览。完整能力见 [状态页](/status/)。

下载后可核对 SHA256：Linux 运行 `sha256sum <文件名>`，Windows PowerShell 运行 `Get-FileHash <文件名> -Algorithm SHA256`。两个下载入口应得到相同文件。哈希用于确认文件完整，不能替代来源确认。本站当前不推荐任何未经核实的商店入口。

## 接下来怎么做

- **普通使用者**：阅读 [应用简介](/getting-started/) 和 [图形界面指南](/guides/gui/)。列表暂时为空时请稍后刷新；网络或校验问题请重试，也可查看版本说明。
- **已有源码访问权限的开发者**：按 [从源码构建](/install/) 准备并排的源码目录及平台工具链。源码权限只是自行构建的前提，不是下载官方安装包的前提。

连接真实账号之前，请阅读 [安全说明](/security/)。
