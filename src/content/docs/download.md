## 当前获取状态

**截至 2026-10-24，本站未提供经核实的公开安装包链接，官网仓库 Releases 未查到公开版本，GUI/Core 未能公开访问。**

这是对已检查公开入口的结论，不等于全球不存在安装包。核实范围与 API 返回结果见 [状态页](/status/)。[官网仓库 Releases](https://github.com/picferry/picferry-website/releases) 是可供查看的公开页面，并非已验证的安装包下载入口或未来发布渠道承诺。

本站目前没有可推荐的商店安装入口，也不列出未经核实的安装包文件名、CPU 架构、发布日期或自动启用的下载按钮。原生工程存在与公开包可下载是两回事。

## 接下来怎么做

- **普通使用者**：先阅读 [应用简介](/getting-started/) 和 [GUI 指南](/guides/gui/)，了解操作流程；以经核实的来源、版本和完整性信息判断安装包可信度，勿仅凭文件名或镜像站说明判断。
- **已有源码访问权限的开发者**：按 [从源码构建](/install/) 准备并排的 GUI/Core 目录及对应平台工具链。公开网站仓库不能替代应用源码。
- **核对设备能力**：查看 [状态页的平台矩阵](/status/#平台与保存目标)。Windows/Linux 有原生工程，Android/iOS/OHOS 有系统图库保存实现；macOS 当前缺少原生工程，Web 仅供 UI 预览，这些均不构成安装包交付承诺。

连接真实账号之前，请阅读 [安全说明](/security/)。
