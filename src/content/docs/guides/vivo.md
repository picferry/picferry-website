PicFerry 已开放新增 vivo 账号，支持云相册浏览、图片预览和复制下载。迁移与云端删除取决于会话协议：**suite 支持，legacy 仅支持复制**。安装包与发布说明见 [下载页](/download/)。

## 连接账号

1. 选择「添加账号」→「vivo」，填写账号名称，打开账号连接页。
2. 按平台完成认证：
	- **桌面**：使用网页登录，在独立的 Chrome、Edge 或 Chromium 中完成 vivo 官方认证并进入相册，回到 PicFerry 点击「已完成登录」；也可导入 Cookie 文件。
	- **OHOS**：使用应用打开的原生网页登录页，完成官方认证后确认登录。
	- **Android / iOS**：使用 Cookie 文件。Android 当前仅注册了小米原生网页登录，vivo 请按 Cookie 流程操作。
3. 等待会话验证并保存，再打开「照片」检查媒体内容。

使用 Cookie 时，在受信任的浏览器登录 [vivo 官方网页](https://pc.vivo.com.cn/suite?origin=cloudWeb#/album/all?folderId=1&clientBucketId=0)，进入相册，将相关 Cookie 导出为 JSON 文件，安全传到运行 PicFerry 的设备，在「Cookie 文件」中选择并保存连接。旧版网页会话可以继续用于复制，应用根据有效凭据选择协议；修改文件名不能把 legacy 会话变为 suite。

网页登录会保存已验证会话，并持久化后续 Cookie 轮换。认证失效时重新登录或导入；请把 Cookie 与会话文件当作凭据保管。

## 复制与迁移

先预览并试存少量照片，再进入批量下载，保持默认「仅下载」（`copy`）。桌面保存到账号目录；Android、iOS、OHOS 默认保存到系统图库。权限、日期目录和 OHOS 保存确认见 [GUI 使用指南](/guides/gui/)。视频下载后可用本机播放器查看，目前不支持 vivo 视频内联播放。

使用 suite 会话时可选择「下载并删除云原件」（`move`）。应用会在运行时检查能力；只有本轮下载并完成原件完整性验证的项目才符合迁移条件，移动端还需要系统图库保存成功的回执。缺少验证依据、待核验聚合资源或已有同名文件，不会仅凭“已存在”就迁移。符合条件的原件移入 vivo 最近删除，恢复期限以 vivo 官方规则为准。

图库中的显式删除也要求 suite 会话，但它是独立操作，不要求先下载或备份。请核对选择和确认信息；legacy 会话继续使用复制模式。

取消会保留已保存媒体，之后重新开始；没有断点续传、自动同步或定时任务。增量模式在遇到第一个已存在目标时停止，补齐旧文件时请关闭。

需要 CLI 时参阅 [从源码构建](/install/) 和 Core 包说明；源码需要相应仓库访问权限。
