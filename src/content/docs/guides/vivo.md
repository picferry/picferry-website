PicFerry 已开放新增 vivo 账号，支持云相册浏览、图片预览和复制下载。添加账号时也可选择 **iQOO**，它使用同一 vivo 云服务，账号仍按 vivo 保存。迁移与云端删除取决于会话协议：**suite 支持，legacy 仅支持复制**。安装包见 [下载页](/download/)。

## 连接账号

1. 选择「添加账号」→「vivo」或「iQOO」，填写账号名称，打开 vivo 账号连接页。
2. 按平台完成认证：
	- **桌面**：使用网页登录，在独立的 Chrome、Edge 或 Chromium 中完成 vivo 官方认证并进入相册，回到 PicFerry 点击「已完成登录」；也可导入 Cookie 文件。
	- **HarmonyOS**：使用应用打开的原生网页登录页，完成官方认证后确认登录。
	- **Android / iOS**：使用 Cookie 文件。
3. 等待会话验证并保存，再打开「照片」检查媒体内容。

使用 Cookie 时，在受信任的浏览器登录 [vivo 官方网页](https://pc.vivo.com.cn/suite?origin=cloudWeb#/album/all?folderId=1&clientBucketId=0)，进入相册，将相关 Cookie 导出为 JSON 文件，安全传到运行 PicFerry 的设备，在「Cookie 文件」中选择并保存连接。旧版网页会话可以继续用于复制，应用根据有效凭据选择协议；legacy 与 suite 由有效凭据决定；文件名保持原样即可。

网页登录会保存已验证会话，并持久化后续 Cookie 轮换。认证失效时重新登录或导入；请把 Cookie 与会话文件当作凭据保管。

## 复制与迁移

先预览并试存少量照片，再进入批量下载，保持默认「仅下载」（`copy`）。桌面保存到账号目录；Android、iOS、HarmonyOS 默认保存到系统图库。权限、日期目录和 HarmonyOS 保存确认见 [图形界面指南](/guides/gui/)。视频下载后可用本机播放器查看。

使用 suite 会话时可选择「下载并删除云原件」（`move`）。应用会在运行时检查能力；只有本轮下载并完成原件完整性验证的项目才符合迁移条件，移动端还需要系统图库保存成功的回执。缺少验证依据、待核验聚合资源或已有同名文件时，迁移以本轮完整性验证和保存回执为准。符合条件的原件移入 vivo 最近删除，恢复期限以 vivo 官方规则为准。

图库中的显式删除也要求 suite 会话，且为独立操作，确认后即可执行；建议事先核对选择。请核对选择和确认信息；legacy 会话继续使用复制模式。

取消会保留已保存媒体，之后重新开始将重新执行任务；任务由用户手动开始。增量模式在遇到第一个已存在目标时停止，补齐旧文件时请关闭。

安装包见 [下载页](/download/)。从源码构建见 [从源码构建](/install/)。
