**当前 GUI 暂未开放新增荣耀账号。** Core 的 HONOR 提供方已经实现真实的 Cookie 认证、媒体列举和复制下载，会向云服务发送实际请求，并非只接收 Cookie 的脚手架。

## 当前使用路径

- 新用户请以 GUI 实际开放的厂商为准，常规流程见 [GUI 使用指南](/guides/gui/)。
- 已有配置的荣耀账号按界面提供的连接与复制能力使用；云端删除和批量迁移未开放。
- 需要 CLI 时，先确认有源码仓库访问权限，再参阅 [从源码构建](/install/) 和 `honor_photos_downloader` 包说明。使用本人官方云服务的有效登录 Cookie，先复制少量媒体并检查结果。

Core 的真实下载能力不代表 GUI 新增账号或媒体预览已经开放，也不意味着支持自动同步、定时任务或断点续传。

## 凭据与发布信息

Cookie、会话文件、账号标识和带签名的媒体 URL 保持私密；反馈问题时仅提供脱敏信息。认证失效后重新登录取得有效 Cookie。

安装包与发布说明见 [下载页](/download/)。GUI/Core 源码需要相应仓库访问权限。
