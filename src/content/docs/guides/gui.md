PicFerry 的图形界面用于连接云相册、浏览媒体并保存到本机。安装包与发布说明见 [下载页](/download/)；需要本地构建时请参阅 [从源码构建](/install/)，GUI/Core 源码需要相应仓库访问权限。

## 1. 添加并连接账号

点击「添加账号」，选择厂商并填写便于识别的账号名称。目前开放新增 [iCloud](/guides/icloud/)、[小米](/guides/xiaomi/) 和 [vivo](/guides/vivo/) 账号；华为、OPPO、荣耀暂未开放新增入口。

| 厂商 | 连接方式 |
| --- | --- |
| iCloud | 应用内输入 Apple ID 与密码，按提示完成双重认证；中国大陆账号选择对应区域 |
| 小米 | 桌面独立浏览器网页登录或 Cookie 文件；Android、OHOS 原生网页登录；iOS 使用 Cookie 文件 |
| vivo | 桌面独立浏览器网页登录或 Cookie 文件；OHOS 原生网页登录；Android、iOS 使用 Cookie 文件 |

桌面网页登录需要安装 Chrome、Edge 或 Chromium。在官方页面完成认证，再回到 PicFerry 确认登录。Cookie 文件与登录会话相当于凭据，请仅保存在受信任的位置；失效后重新登录或导入。详细步骤见对应厂商指南。

## 2. 浏览并试存少量媒体

连接后打开「照片」，浏览列表或云端相册，选择媒体查看预览或单项下载。iCloud、小米、vivo 支持图片预览；**视频内联播放仅限 iCloud 返回 `small_video` 资源时**，其他情况可下载后用本机播放器查看。

先试存少量照片和视频，确认文件可打开、保存位置正确，再开始大批量下载。Live Photo 的相关资源保存不代表系统图库一定会将其还原为成对的实况照片。

## 3. 设置保存目标并批量下载

在账号的批量下载页确认保存目标，保持默认「仅下载」（`copy`），选择全部媒体、仅照片或仅视频；「新增下载数量」留空表示不限数量。默认并发为 **4**，可在任务中调整，也可在设置中修改默认值。

| 平台 | 保存位置与要求 |
| --- | --- |
| Windows / Linux | 本地目录；可选择并打开保存文件夹，默认按账号分隔 |
| Android | 默认保存到系统图库，按系统提示授权 |
| iOS | 默认保存到系统照片图库，需要完整照片访问权限 |
| OHOS | 默认保存到系统图库；保持应用在前台并确认系统保存对话框，每批最多 100 项 |

桌面批量下载默认在账号目录内按 **UTC 年/月/日**组织（`YYYY/MM/DD`），因此可能与本地时区显示日期不同；图库单项下载直接放入账号目录。移动端使用 PicFerry 归档，**不会重建云端相册结构**。图库中的相册浏览也不等于批量下载会按相册分目录归档。

点击「开始下载」后查看进度与结果。取消会保留已经保存的媒体；之后可重新开始任务，**不是断点续传**。默认流程会识别已有目标；启用「增量模式」则在遇到第一个已存在目标时停止，适合补充最新内容，不适合补齐旧文件缺口。当前没有自动同步或定时任务。

## 4. 按需迁移或删除云端媒体

- **复制（默认）**：保存到本机，保留云端原件，适合首次备份。
- **迁移（`move`）**：选择「下载并删除云原件」，阅读确认信息后执行。iCloud、小米、vivo 支持，其中 vivo 仅限 suite 会话，legacy 会话使用复制模式。迁移会改变云端数据，也可能影响使用同一云服务的设备。

迁移不是“看到同名文件就删”：iCloud 按所选资源组的完成状态及厂商规则判断；小米、vivo 需要本轮下载的原件完整性验证。移动端还需要成功保存到系统图库的回执，验证不足或保存未确认的项目保留云端。建议先用复制模式核对备份，再决定是否迁移。

**图库中的显式删除是独立操作**：它不要求先下载或备份，也不等同于迁移的验证流程。请在确认对话框中核对所选媒体；恢复期限以厂商规则为准，vivo 删除同样受 suite 会话能力限制。

## 设置与账号管理

设置支持中英文、跟随系统/浅色/深色主题、图库网格密度及默认下载参数。移除账号仅删除应用内账号配置，**不会清理会话、缓存、已下载媒体或云端内容**；它不等同于退出云服务或撤销会话授权。
