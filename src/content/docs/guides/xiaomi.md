PicFerry 已开放新增小米账号，支持云相册浏览、图片预览、复制下载与可选迁移。安装包与发布说明见 [下载页](/download/)。请先确认目标账号仍能在小米官方网页访问所需云端媒体，服务可用范围以小米为准。

## 连接账号

1. 选择「添加账号」→「Xiaomi」，填写账号名称，打开账号连接页。
2. 按平台选择登录方式：
	- **桌面**：点击网页登录，在独立的 Chrome、Edge 或 Chromium 中完成官方认证，进入云相册，再回到 PicFerry 点击「已完成登录」。也可选择 Cookie 文件。
	- **Android / OHOS**：使用应用打开的原生网页登录页，在小米官方页面完成认证，再点击「完成登录」。
	- **iOS**：使用 Cookie 文件登录。
3. 等待会话验证并保存，进入「照片」检查是否为目标账号。

使用 Cookie 时，在受信任的浏览器登录 [小米云服务](https://i.mi.com)，进入云相册，将相关 Cookie 导出为 JSON 文件，安全传到运行 PicFerry 的设备，在「Cookie 文件」中选择并保存连接。保留域名等记录字段，以便匹配服务请求；Cookie 和会话文件仅在本地安全保管。

若桌面找不到浏览器，安装 Chrome、Edge 或 Chromium 后重试，或改用 Cookie。Cookie 的到期提示不保证服务端会话始终有效；认证失效时重新登录或导入。

## 下载与迁移

先预览并下载少量媒体，确认结果后进入批量下载，默认使用「仅下载」（`copy`）。桌面保存到账号目录；Android、iOS、OHOS 默认保存到系统图库。目录组织、权限和 OHOS 保存确认见 [GUI 使用指南](/guides/gui/)。视频可下载后播放，目前不支持小米视频内联播放。

选择「下载并删除云原件」（`move`）时，只有**本轮下载且完成原件完整性验证**的媒体才符合迁移条件；移动端还要获得系统图库保存成功的回执。已有同名文件、缺少校验依据或仍待核验的聚合资源，不构成删除依据。删除会同步影响已登录小米云服务的设备，请先核对备份与确认信息。

图库中的显式删除是独立云端操作，不要求预先下载或备份；恢复规则以小米为准。取消下载保留已保存内容，后续需重新开始，不提供断点续传或自动同步。增量模式遇到第一个已存在目标就停止，补齐旧文件时请关闭。

需要 CLI 时参阅 [从源码构建](/install/) 和 Core 包说明；源码需要相应仓库访问权限。
