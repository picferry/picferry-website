**当前 GUI 暂未开放新增 OPPO 账号。** Core 已有基于有效登录 Cookie 的真实认证、媒体列举与复制下载实现，不应将它理解为“尚不能下载”的脚手架。

## 当前使用路径

- 新用户请使用 GUI 当前开放的厂商入口，操作流程见 [GUI 使用指南](/guides/gui/)。
- 已有配置的 OPPO 账号按界面提供的连接与复制能力使用；云端删除和批量迁移未开放。
- 需要底层 CLI 的用户，先确认具有源码仓库访问权限，再参阅 [从源码构建](/install/) 与 `oppo_photos_downloader` 包说明。使用本人官方云服务登录会话，先验证少量复制下载及保存结果。

Core 的复制能力不代表 GUI 已开放新增账号或媒体预览，也不提供自动同步、定时任务或断点续传承诺。Cookie 和会话文件仅保存在受信任的位置；失效后重新登录取得有效凭据。

安装包与发布说明见 [下载页](/download/)，以该页实际提供的信息为准。
