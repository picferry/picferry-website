## 公开发布核实

**截至 2026-10-24，首个正式版本尚未发布。** 官方编译包的公开渠道已确定为 R2 主下载与官网仓库 GitHub Releases 备用下载；当前受控自动构建目标为 Linux x64、Windows x64 和 Android universal APK，目标存在不代表包已经发布。

当天通过公开 GitHub API 核实：`picferry/picferry-website` 仓库返回 200，其 latest release 返回 404；`picferry/picferry_gui` 和 `picferry/picferry_core` 的仓库与 latest release 均返回 404。这只说明上述公开入口的核实结果，不等于全球不存在安装包，也不能据此判断受限仓库内的内容。

公开网站仓库为 [picferry/picferry-website](https://github.com/picferry/picferry-website)，其 Releases 承载官方编译产物。GUI/Core 源码权限与编译包分发分别管理，源码受限不表示无法下载官方包。[下载页](/download/) 在浏览器中读取 R2 的 `picferry/release/latest.json`，以校验后的实时清单显示版本、架构、大小、SHA256 与双渠道链接；404 显示首发等待，网络失败另行提示。已有源码权限时见 [从源码构建](/install/)。这里不承诺商店上架或发布日期。

## 平台与保存目标

| 平台 | 当前工程状态 | 保存目标与前提 |
| --- | --- | --- |
| Windows | 有原生工程 | 本地目录；需要对应桌面构建工具链 |
| Linux | 有原生工程 | 本地目录；需要对应桌面构建工具链 |
| Android | 有原生工程 | 系统图库，按系统要求授权 |
| iOS | 有原生工程 | 系统照片图库，需要完整照片访问权限及 Apple 构建、签名环境 |
| OHOS | 有原生工程 | 系统图库；应用保持前台并确认系统保存对话框，每批最多 100 项；使用隔离的 OHOS 构建环境 |
| macOS | 有 Dart 平台分支，但当前没有 `macos/` 原生工程 | 不列为当前可交付平台 |
| Web | 仅 UI 预览 | 没有真实云服务连接或下载能力 |

桌面批量下载默认在账号目录内按 **UTC 年/月/日（`YYYY/MM/DD`）**归档，图库单项下载直接放入账号目录。移动端使用 **PicFerry** 归档；保存不会重建云端相册结构。工程状态与公开包可用性分别核实。

## 下载、迁移与删除

| 操作 | 当前行为与边界 |
| --- | --- |
| 复制（`copy`，默认） | 保存到本机并保留云端原件 |
| 迁移（`move`） | 仅 iCloud、小米、vivo；vivo 需要 suite 会话。删除前需要资源校验，移动端还需要系统图库保存成功回执 |
| 迁移资源校验 | iCloud 按所选资源组完成状态及厂商规则判断；小米、vivo 要求本轮下载原件的完整性验证；验证不足或保存未确认时保留云端原件 |
| 图库显式删除 | 独立的云端删除动作，不要求先下载或备份，也不经过迁移的保存校验；受厂商/会话能力约束，vivo 删除同样要求 suite |
| 取消任务 | 保留已经保存的媒体；已提交的云端删除仍可能生效，取消不回滚这些操作 |
| 再次开始 | 可重新执行任务，但不是断点续传；当前没有 `sync` 模式、自动同步或定时任务 |
| 增量模式 | 遇到第一个已存在目标即停止，不是哈希去重，也不是完整补齐旧文件缺口 |
| 图库相册选择 | 用于浏览，不限定批量下载范围，也不代表按云端相册重建归档 |

迁移和显式删除都可能影响同一云服务下的其他设备；操作前阅读 [安全说明](/security/)。

## 浏览、设置与本地数据

- iCloud、小米、vivo 支持图片预览；视频内联播放仅限 iCloud 返回 `small_video` 资源的情况，其他视频可下载后用本机播放器查看。
- 保存 Live Photo 相关资源不保证系统图库将其还原为成对的实况照片。
- 设置支持中英文、跟随系统/浅色/深色主题、图库密度和默认下载参数；默认并发为 **4**。
- 账号配置、Cookie/会话文件和预览、元数据缓存保存在本机，没有统一加密保证。
- 移除账号只移除应用内账号配置，不清理会话、缓存、已下载媒体或云端内容，也不等同于撤销厂商授权。

完整操作步骤见 [GUI 指南](/guides/gui/)，职责分层见 [架构](/architecture/)。
