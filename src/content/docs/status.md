## 公开发布核实

官方安装包可在 [下载页](/download/) 获取。当前覆盖 Linux x64、Windows x64 和 Android；macOS、iOS、HarmonyOS 走应用市场或其他独立渠道。实际可用包以该页列表为准。

打开 [下载页](/download/) 即可获取官方安装包。源码访问与公开发布分别核实；已有源码权限时见 [从源码构建](/install/)。商店上架进度与官网下载分别核实。

## 平台与保存目标

| 平台 | 官网下载 | 保存位置 |
| --- | --- | --- |
| Windows | 有 x64 安装包 | 本地目录 |
| Linux | 有 x64 安装包 | 本地目录 |
| Android | 有 universal APK | 系统图库，按系统要求授权 |
| iOS | 应用市场或其他独立渠道 | 系统照片图库，需要完整照片访问权限 |
| HarmonyOS | 应用市场或其他独立渠道 | 系统图库；应用保持前台并确认系统保存对话框，每批最多 100 项 |
| macOS | 应用市场或其他独立渠道 | 本地目录 |
| Web | 仅界面预览 | 界面预览；真实云服务连接与下载以已发布客户端为准 |

桌面批量下载默认在账号目录内按 **UTC 年/月/日（`YYYY/MM/DD`）**归档，图库单项下载直接放入账号目录。移动端使用 **PicFerry** 归档规则保存。平台能力与官网安装包分别核实。

## 下载、迁移与删除

| 操作 | 当前行为与边界 |
| --- | --- |
| 复制（`copy`，默认） | 保存到本机并保留云端原件 |
| 迁移（`move`） | 面向 iCloud、小米、vivo；vivo 需要 suite 会话。删除前需要资源校验，移动端还需要系统图库保存成功回执 |
| 迁移资源校验 | iCloud 按所选资源组完成状态及厂商规则判断；小米、vivo 要求本轮下载原件的完整性验证；校验未完成或保存待确认时保留云端原件 |
| 图库显式删除 | 独立的云端删除动作，确认后即可执行；建议事先核对所选项目。它使用自身确认流程，与迁移的保存校验分开；受厂商/会话能力约束，vivo 删除同样要求 suite |
| 取消任务 | 保留已经保存的媒体；已提交的云端删除仍可能生效，已提交的删除保持生效 |
| 再次开始 | 重新执行任务；任务由用户手动开始 |
| 增量模式 | 遇到第一个已存在目标即停止，用于补充最新内容；旧文件缺口需另选任务范围核对 |
| 图库相册选择 | 用于浏览；批量下载范围以任务设置为准，归档按 PicFerry 规则保存 |

迁移和显式删除都可能影响同一云服务下的其他设备；操作前阅读 [安全说明](/security/)。

## 浏览、设置与本地数据

- iCloud、小米、vivo、OPPO 支持图片预览；视频内联播放仅限 iCloud 返回 `small_video` 资源的情况，其他视频可下载后用本机播放器查看。
- 保存 Live Photo 相关资源后，系统图库中的成对还原以系统实际结果为准。
- 设置支持中英文、跟随系统/浅色/深色主题、图库密度和默认下载参数；默认并发为 **4**。
- 账号配置、Cookie/会话文件和预览、元数据缓存保存在本机，加密范围按数据类型分别评估。
- 移除账号只移除应用内账号配置；会话、缓存、已下载媒体与云端内容保持原状。撤销厂商授权在厂商侧完成。

完整操作步骤见 [图形界面指南](/guides/gui/)。
