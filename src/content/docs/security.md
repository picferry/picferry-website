## 非官方与网络边界

PicFerry 不是 Apple、华为、小米、vivo、OPPO 或荣耀的官方产品，也不由这些厂商支持。厂商网页、API、风控和会话规则可能变化，影响认证与下载。

当前实现由本机直接连接厂商服务，未见 PicFerry 自有中转服务参与认证或媒体传输。这不是离线应用：登录、浏览云端媒体、下载和云端删除都需要网络，也受厂商服务规则约束。此描述不等同于完整安全审计或所有依赖的隐私保证。

## 认证信息进入哪里

- **iCloud**：Apple ID 与密码进入应用内认证流程，并按提示完成双重认证；支持中国大陆账号区域。不能将其描述为“密码从不进入应用”。
- **小米、vivo**：根据平台使用官方网页认证或导入 Cookie 文件。Cookie 和会话可代表账号权限，应按凭据管理。具体入口见 [状态页](/status/#厂商与认证)。
- **华为、OPPO、荣耀**：GUI 暂未开放新增账号，但 Core 已有真实复制下载实现，不能假设其代码不会产生网络请求。

请只在本人信任的设备和认证页面操作。密码、验证码由用户通过应用或厂商认证界面输入；反馈问题时使用脱敏信息。

## 本地存储不等于统一加密

应用会在本地保存账号配置、Cookie/会话文件，以及预览和元数据缓存；下载的照片与视频保存到所选目录或系统图库。当前没有覆盖这些数据的统一加密保证，也不能仅凭“本地保存”推断所有凭据都由系统钥匙串保护。

- 将 Cookie、会话文件、账号配置及缓存放在受访问控制的设备和目录中；备份这些数据时使用受保护的备份方式。
- 公开日志、截图、Issue 和 PR 使用脱敏副本，去除密码、验证码、Cookie、session、账号/设备标识及签名媒体 URL。
- **移除账号只移除应用内账号配置**，不会清理会话、缓存、已下载媒体或云端内容，也不等同于退出厂商服务或撤销授权。需要撤销会话时，使用厂商提供的账号安全管理入口，并另行处理本机残留数据。

## 复制、迁移与显式删除

默认 **`copy`（仅下载）**保留云端原件。建议先试存少量媒体并核对文件可读、保存位置及备份结果，再决定是否使用迁移。

**`move`（下载并删除云原件）**仅面向 iCloud、小米、vivo，其中 vivo 要求 suite 会话，legacy 会话使用复制。迁移需要资源校验：iCloud 按所选资源组完成状态及厂商规则判断，小米和 vivo 要求本轮下载原件的完整性验证。移动端还需要系统图库保存成功回执；验证不足或保存未确认的项目保留云端原件。

**图库中的显式删除是独立操作，不要求先下载或备份，也不使用迁移的保存校验流程。**请在确认对话框中核对所选项目；vivo 删除同样受 suite 会话能力限制。云端删除可能影响使用同一云服务的其他设备，恢复方式与期限由厂商决定。

系统图库保存有平台前提：iOS 需要完整照片访问权限；OHOS 要求应用保持前台并确认系统保存对话框，每批最多 100 项。完整能力边界见 [状态页](/status/)。

## 取消与再次开始

取消任务会保留已经保存的媒体。**已经提交的云端删除仍可能生效，取消不是回滚。**再次开始是重新执行任务，不是断点续传。

增量模式遇到第一个已存在目标即停止，不是哈希去重，也不能用于证明所有旧文件缺口已补齐。图库相册选择不限定批量下载范围；迁移前应核对实际任务范围，而不是将正在浏览的相册当作下载边界。当前没有自动同步或定时任务。

操作说明见 [GUI 指南](/guides/gui/)，对外反馈方式见 [贡献](/contributing/)。
