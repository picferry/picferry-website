PicFerry 是非官方的云相册下载应用：连接账号、浏览照片和视频，再将媒体保存到桌面目录或移动端系统图库。

## 当前可以做什么

- 新增并连接 **iCloud、小米、vivo、OPPO** 账号。添加账号时也可选择 REDMI、POCO、iQOO、OnePlus、realme，它们分别使用小米、vivo 或 OPPO 云服务。华为、荣耀暂未开放新增账号。
- 浏览媒体、预览图片并下载；默认使用「仅下载」（`copy`），保留云端原件。
- 按条件使用「下载并删除云原件」（`move`）；迁移与图库中的显式删除是不同操作，操作前请阅读 [安全说明](/security/)。
- 设置中文或英文、跟随系统/浅色/深色主题、图库密度及下载参数；默认并发为 **4**。

具体认证方式、平台能力和操作限制统一见 [状态页](/status/)。某项能力已经实现，不等于已经提供可下载的安装包；获取渠道见 [下载页](/download/)。

## 开始使用

1. 阅读 [安全说明](/security/)，了解认证信息、本地保存和云端删除的边界。
2. 打开 [下载页](/download/)，选择适合你设备的官方安装包。当前覆盖 Linux x64、Windows x64 和 Android；macOS、iOS、OHOS 走应用市场或其他独立渠道。下载官方安装包不需要源码权限；已有源码权限的开发者也可参考 [从源码构建](/install/)。
3. 按 [图形界面指南](/guides/gui/) 添加账号，再阅读 [iCloud](/guides/icloud/)、[小米](/guides/xiaomi/)、[vivo](/guides/vivo/) 或 [OPPO](/guides/oppo/) 的认证步骤。
4. 先用复制模式试存少量照片和视频，确认保存位置和文件可读，再执行批量任务。

当前没有自动同步或定时任务，重新开始任务也不是断点续传。图库里的相册选择不限定批量下载范围，保存时不会重建云端相册结构；详细行为见 [状态页](/status/)。
