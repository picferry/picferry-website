PicFerry 是非官方的云相册下载应用：连接账号、浏览照片和视频，再将媒体保存到桌面目录或移动端系统图库。Flutter 图形界面是日常操作入口，底层由 Dart 厂商包和共享核心提供能力。

## 当前可以做什么

- 新增并连接 **iCloud、小米、vivo** 账号；华为、OPPO、荣耀的新增账号入口暂未开放，但 Core 已有真实的复制下载实现。
- 浏览媒体、预览图片并下载；默认使用「仅下载」（`copy`），保留云端原件。
- 按条件使用「下载并删除云原件」（`move`）；迁移与图库中的显式删除是不同操作，操作前请阅读 [安全说明](/security/)。
- 设置中文或英文、跟随系统/浅色/深色主题、图库密度及下载参数；默认并发为 **4**。

具体认证方式、原生平台能力和操作限制统一见 [状态页](/status/)。工程中具备某项能力，不等于已经提供公开安装包；获取渠道见 [下载页](/download/)。

## 开始使用

1. 阅读 [安全说明](/security/)，了解认证信息、本地保存和云端删除的边界。
2. 查看 [下载页](/download/) 的实时发布清单，选择 R2 主下载或 GitHub 备用并核对 SHA256。截至 2026-10-24 首个正式版本尚未发布；Linux x64、Windows x64、Android universal APK 为当前自动构建目标，实际包以清单为准。公开编译包不要求 GUI/Core 源码权限；已有源码权限的开发者也可参考 [从源码构建](/install/)。
3. 按 [GUI 指南](/guides/gui/) 添加账号，再阅读 [iCloud](/guides/icloud/)、[小米](/guides/xiaomi/) 或 [vivo](/guides/vivo/) 的认证步骤。
4. 先用复制模式试存少量照片和视频，确认保存位置和文件可读，再执行批量任务。

当前没有自动同步或定时任务，重新开始任务也不是断点续传。图库里的相册选择不限定批量下载范围，保存时不会重建云端相册结构；详细行为见 [状态页](/status/)。
